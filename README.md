# Keepr 🚀

Keepr is a modern and intuitive mobile application designed to help you regain control over your digital life. Declutter your storage with an engaging "Swipe-to-Action" experience.

## ✨ Features

-   **Tinder-Style Swiping:** Review your photos and videos effortlessly with smooth animations.
-   **Privacy First:** All processing is done locally on your device. Your data stays yours.
-   **Smart Filtering:** Organize your gallery by specific albums, media types, or storage locations.
-   **Gamified Experience:** Earn unique badges and track your progress through a comprehensive achievement system.
-   **Insightful Statistics:** See exactly ne kadar storage space you’ve reclaimed.
-   **Multilingual Support:** Localized in Turkish, English, Spanish, German, French, and Portuguese.
-   **Modern Aesthetics:** Sleek UI with full Dark and Light mode support.

## 🛠️ Built With

-   [React Native](https://reactnative.dev/)
-   [Expo](https://expo.dev/)
-   [Zustand](https://github.com/pmndrs/zustand) (State Management)
-   [React Native Reanimated](https://www.reanimated2.com/) (Animations)

## 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Ader-Land/Keepr.git
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run the application:**
    ```bash
    npx expo start
    ```
