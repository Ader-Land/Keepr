# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project follows
[Semantic Versioning](https://semver.org/).

## [1.0.0] - Unreleased

### Added
- Swipe-to-keep / swipe-to-delete gallery cleaner for photos and videos, with undo and a review bin.
- Persistent keep list, filters (media type, album, sort order), statistics and badges.
- Optional daily/weekly local reminders.
- English, Turkish, Spanish, German, French and Portuguese translations.
- Light, dark and system themes.
- Open-source release tooling: GPL-3.0 license, CI, release workflow, EAS profiles, contribution and security docs.

### Changed
- Reduced Android permissions to the minimum needed; location, audio and media-location access are blocked.
- Targets Android API 36.
