# Code of Conduct

We want Keepr to be a welcoming project for everyone. This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

- Be respectful, patient and constructive.
- Welcome people of all backgrounds and experience levels.
- Give and accept feedback gracefully; focus on what is best for the project.
- No harassment, discrimination, personal attacks, or publishing others' private information.

## Enforcement

Maintainers may edit, remove or reject contributions and comments that violate this code, and may temporarily
or permanently ban contributors for inappropriate behaviour. Report concerns privately through
[GitHub Security Advisories](https://github.com/Ader-Land/Keepr/security/advisories/new) or by contacting the
maintainer through their GitHub profile.
