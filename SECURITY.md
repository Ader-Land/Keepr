# Security Policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead:
**Security → Report a vulnerability** at <https://github.com/Ader-Land/Keepr/security/advisories/new>.

Include a description, reproduction steps, the affected version and the potential impact. You can expect an
initial response within about 7 days. Please allow reasonable time for a fix before public disclosure.

## Scope

Keepr runs offline and has no backend. Relevant reports include unintended data exposure, unsafe deletion
behaviour, excessive permissions and vulnerable dependencies that affect the shipped app.
